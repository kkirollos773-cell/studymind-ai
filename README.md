# مسابقة مبادئ القانون

تطبيق ويب تفاعلي لإدارة مسابقة أسئلة قانونية بين فريقين. الواجهة عربية وتدعم تغيير اللغة من إعدادات المالك، وتُحفظ الأسئلة والنتائج على نفس الجهاز باستخدام التخزين المحلي في المتصفح.

## تشغيل سريع

- افتح `index.html` في المتصفح للتجربة المحلية.
- لتشغيل التثبيت وميزات العمل دون اتصال بصورة صحيحة، ارفع محتويات المجلد إلى GitHub Pages أو شغّلها عبر خادم محلي؛ Service Worker لا يعمل من `file://`.
- ميزة استخراج الأسئلة من PDF تحتاج اتصالًا بالإنترنت لتحميل مكتبة PDF.js من CDN.

## الرفع إلى GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع كل الملفات الموجودة في جذر هذا المجلد، مع التأكد من وجود `index.html` في الجذر.
3. من **Settings → Pages** اختر النشر من الفرع الرئيسي `main` ومن المجلد `/ (root)`، ثم احفظ.
4. بعد اكتمال النشر افتح رابط GitHub Pages الذي يظهر في إعدادات المستودع.

## الملفات

- `index.html` — التطبيق كاملًا.
- `manifest.json` و`icon.svg` و`apple-touch-icon.png` — بيانات التطبيق وأيقوناته.
- `sw.js` — تخزين ملفات الواجهة مؤقتًا لتسريع الفتح ودعم فتح التطبيق دون اتصال بعد زيارته أول مرة.
